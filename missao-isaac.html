Um alfabeto disfarçado

A cifra de Vigenère é um jeito de esconder mensagens trocando letras. A troca muda a cada posição, seguindo uma palavra-chave.

A chave desta missão é ISAAC. A tabela abaixo ajuda a desfazer cada troca e descobrir a mensagem original.

Pensa na chave como um mapa: ela indica qual linha da tabela usar para encontrar cada letra verdadeira.

Prepara tua folha

  1. Copia o código ITRA Q XGRTCT.
  2. Embaixo dele, repete ISAACISAAC..., colocando uma letra da chave abaixo de cada letra do código.
  3. Pula os espaços: eles não gastam letras da chave. Não reinicia a chave a cada palavra.
  4. Deixa uma terceira linha vazia para escrever as letras que descobrir.

Como descobrir uma letra

  1. Olha a letra da chave no papel e encontra essa linha na coluna verde da esquerda.
  2. Nessa linha, procura a letra do código secreto.
  3. Sobe nessa mesma coluna até o alfabeto verde do topo. A letra do topo é a resposta!
  4. Anota no papel e repete para a próxima letra. No fim, mantém os espaços do código.
Treino separado da missão: se a letra da chave for B e a do código for D, procura D na linha B. No topo dessa coluna está C. Então a letra descoberta é C.
